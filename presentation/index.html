AI 위임 전

요구사항부터 규칙 문서까지, 사람이 준비한 6단계

Phase 1~4 구현을 AI에게 맡기기 전에, AI가 무엇을 얼마나 정확히 만들어야 하는지부터 사람이 직접 정리했다.

1

요구사항 문서 작성

ChatGPT와 대화하며 문제 정의와 요구사항을 문서로 정리.

2

SPEC.md 작성

요구사항 문서를 기준으로 입력/출력 스키마, 에러 코드, 전송 방식을 SPEC.md에 확정.

3

backlog.json / tools/backlog.mjs 작성

SPEC.md 기반으로 작업 단위를 쪼개고, 상태를 관리할 backlog.json과 읽기/쓰기 도구를 작성.

4

CLAUDE.md 작성

명령어, 프로젝트 구조, 항상 지킬 것을 CLAUDE.md에 정리해 AI가 참고하도록 함.

5

rules 작성

hooks는 사용하지 않고, .claude/rules/에 규칙 문서로만 제약을 명시.

6

필요한 skills 다운로드

작업에 필요한 skill들을 미리 준비해, AI가 위임받은 작업을 곧바로 수행할 수 있게 함.

AI에게 맡긴 것

Phase 1~4 전부 — 사람이 짠 코드는 없다

1

Phase 1~4 구현

Synthetic Dataset 생성, CatBoost 모델 학습, Inference 모듈, MCP 서버 개발까지 전체 파이프라인.

2

전송 방식 리팩터링

전송 방식을 stdio에서 로컬 전용 HTTP로 바꾸고, .mcp.json·PLAN.md·SPEC.md까지 함께 수정.

3

버그 재현·수정

catboost import를 워커 스레드에서 메인 스레드로 옮겨, 응답이 멈추던 문제를 재현하고 고침.
