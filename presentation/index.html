이 Tool이 하는 일

predict_luminance 하나로 Host/Dopant 조합의 예상 Luminance를 즉시 확인할 수 있다 — 물성치 조합을 바꿔가며 여러 후보를 빠르게 스크리닝하고, 실제 소자 제작 전에 가능성 있는 조합만 추려내는 용도다.

핵심 기능

predict_luminance — 입력 14개, 출력 1개

14개 필드는 세 그룹이다 — Host 물성치 5개(ID + HOMO/LUMO/T1/S1), Dopant 물성치 5개(ID + HOMO/LUMO/T1/S1), EML 구조·구동조건 4개(두께·농도·전압·전류밀도). 이 조합으로 Luminance 하나를 예측해 반환한다.

입력 
{
  "host_material_id": "HOST_001",
  "host_homo": -5.70,
  "host_lumo": -2.60,
  "host_t1": 2.80,
  "host_s1": 3.10,
  "dopant_material_id": "DOPANT_001",
  "dopant_homo": -5.50,
  "dopant_lumo": -2.80,
  "dopant_t1": 2.50,
  "dopant_s1": 2.90,
  "eml_thickness_nm": 30.0,
  "dopant_concentration_percent": 8.0,
  "voltage_v": 4.2,
  "current_density_ma_cm2": 10.0
}
출력 
{
  "luminance_cd_m2": 12543.2
}

입력 스키마

Host/Dopant 물성치와 구동조건

학습 데이터가 이 범위 안에서 생성됐다 — 값의 정확도를 보장하는 기준은 아니다.

필드의미범위
HOMO (eV)최고 점유 분자궤도 준위 — 정공 주입과 관련−6.0 ~ −5.0
LUMO (eV)최저 비점유 분자궤도 준위 — 전자 주입과 관련−3.0 ~ −2.0
T1 (eV)삼중항 여기 에너지2.0 ~ 3.0
S1 (eV)단일항 여기 에너지2.5 ~ 3.5
EML 두께 (nm)발광층 두께10 ~ 50
Dopant 농도 (%)Host 대비 Dopant 도핑 비율1 ~ 15
전압 (V)소자 구동 전압3.0 ~ 6.0
전류밀도 (mA/cm²)소자 구동 전류밀도1 ~ 20
Luminance (cd/m², 출력)예측 대상 — 소자 밝기100 ~ 30,000

Tool 응답

검증 통과 시 HTTP JSON으로 결과 반환

중요

학습 데이터가 완전 무작위로 생성된 Synthetic 데이터라 예측값에 물리적 신뢰성은 없다 — MCP 파이프라인이 정상 동작하는지 확인하기 위한 프로토타입이다.

사용 방법

서버를 띄우고 Claude Code에 등록

1

서버 실행

py -3.12 mcp_server/server.py로 로컬 전용 HTTP 서버(127.0.0.1:8090)를 띄운다.

2

Claude Code 등록 확인

.mcp.json에 이미 등록돼 있다. claude mcp list로 연결 상태를 확인한다.

{
  "mcpServers": {
    "oled-luminance": { "type": "http", "url": "http://127.0.0.1:8090/mcp" }
  }
}
3

Tool 호출

Claude Code 세션에서 predict_luminance를 부르면 예측값이 바로 돌아온다.

HTTP 서버는 Claude Code가 대신 실행해주지 않는다 — 연결하기 전에 사람이 먼저 띄워둬야 한다.

에러 응답

검증 실패 시 공통 에러 스키마

범위 검증은 하지 않는다 — 14개 필수 필드 존재, JSON 구조, 필드 타입만 확인한다.

{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid predict_luminance input.",
    "details": { "field": "host_homo", "reason": "required field missing" }
  }
}
에러 코드발생 조건
VALIDATION_ERROR필수 필드 누락 · 타입 불일치 · 구조 오류
MODEL_NOT_LOADED.cbm 파일 없음 또는 로드 실패
INTERNAL_ERROR그 외 서버 내부 예외

데모

자연어로 물어보면 파라미터를 뽑아 호출한다

규칙 기반 파서가 자연어 문장에서 14개 필드를 추출하고, 실제 MCP HTTP 프로토콜로 predict_luminance를 호출해 결과를 자연어로 요약해 보여준다.
